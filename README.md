# CDX Slider

Save your project context and pick up where you left off in another Codex conversation—even after changing accounts. Your notes and checkpoints stay on your computer.

[한국어](README.ko.md) · English by default, select KR for Korean.

![CDX Slider Work, Account, and Switch panels](docs/assets/images/CDX-slider.webp)
*Panel preview with sample data. Display requires a host that supports MCP Apps.*

## Get started

Follow the [installation guide](docs/assets/Installation.md) from prerequisites through cloning, building, and registering and enabling the Codex plugin. Uninstall instructions are on the same page.

In a new Codex task, run:

```text
$cdx-slider:slider-continuity
```

Register your project, choose **Save this conversation** before leaving, then **Resume saved work** in your next conversation. Wait for the agent to confirm the save.

Saved context helps you continue work; it does not restore the original chat history. The optional macOS bar’s resume relay is experimental.
