# 변경 기록

[English](ChangeLog.md) · [문서 목록](../README.md)

공개 릴리스가 아닌 로컬 개발 이력입니다. 패키지 버전은 0.1.0입니다.

## 미배포 변경

- 영문·한국어 README를 목적, 패널 화면, 시작 방법 중심으로 축약했습니다.
- 설치·기능 상세·설계·유지보수 문서를 `docs/assets/`로 모았습니다.
- PiP 자동 전환, 재시작 동의 기본값, 워크스페이스 조회의 오래된 설명을 수정했습니다.
- 소스 내보내기와 플러그인 준비에서 문서·이미지 목록을 공유하고 링크 및 이전 문서 제거를 검사합니다.
- 초기 개발 관찰 기록은 배포에서 제외하고 `docs/assets/history/`에 보관합니다.

## 초기 개발 — 0.1.0

초기 로컬 Git 이력은 개발 순서대로 묶었습니다.

1. 프로젝트 구성과 MIT 라이선스.
2. 로컬 프로젝트 메모리·권한·체크포인트·Markdown 인계.
3. 계정·사용량 조회와 로컬 로그인 제어.
4. macOS 미니바·고유 ID 기반 대화 선택·실험적 불러오기 중계.
5. Codex MCP 도구와 연속 작업 스킬.
6. EN 기본·KR 선택 패널과 별도 미니바 언어 설정.
7. 설치·설계·릴리스 검증 문서.
8. 로컬 플러그인 준비·소스 내보내기·외부 라이선스 고지.

검증 결과와 한계는 [수용 테스트](acceptance.ko.md)에 정리합니다. 자동 테스트·모의 호스트 결과는 실제 백그라운드 중계, 데스크톱 계정 전환, 에이전트의 작업 완료를 증명하지 않습니다.
