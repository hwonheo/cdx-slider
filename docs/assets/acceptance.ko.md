# 수용 테스트

[English](acceptance.md) · [문서 목록](../README.md)

자동 테스트는 서로 다른 `CODEX_HOME`과 새 MCP 프로세스에서 저장 내용을 복원합니다. 실제 데스크톱 로그인·워크스페이스 선택·패널 표시·에이전트 실행 완료는 별도로 확인해야 합니다. 선택한 프로필 사이에서 공유해도 되는 테스트 프로젝트를 사용하세요.

## 설치와 패널

1. 플러그인을 설치·활성화하고 새 Codex 작업을 엽니다.
2. 다른 요청 없이 `$cdx-slider:slider-continuity`를 호출합니다. `slider_panel`을 요청해야 하며, 패널 열기만으로 저장·로그인·재시작하면 안 됩니다.
3. 패널이 실제로 표시되는지 확인합니다. 도구 성공이나 UI 지원 광고만으로 표시 성공을 판단하지 않습니다.
4. 등록 프로필·프로젝트 목록을 요청하고 `profiles_list`, `projects_list` 응답을 확인합니다. 첫 실행의 빈 목록은 정상입니다.
5. 도구가 없으면 플러그인 활성화와 Node·서버 경로를 확인합니다. 호출 문구를 반복해서 바꾸기보다 연결 누락을 알립니다.

## 언어와 조작

1. 저장된 언어 설정이 없으면 EN이 기본인지 확인합니다.
2. KR을 선택하고 새로고침합니다. 브라우저 저장소를 사용할 수 있으면 선택이 유지되어야 합니다. 저장소가 차단되어도 현재 세션의 전환은 동작해야 합니다.
3. 라벨·접근성 이름·상태·날짜 표시가 바뀌고, 사용자가 작성한 프로젝트 이름·체크포인트 내용은 그대로인지 확인합니다.
4. 키보드 탭 이동과 좁은 화면을 확인합니다. 호스트가 지원하지 않는 기능은 설명과 함께 비활성화되어야 합니다.
5. 미니바의 언어는 CDX 메뉴에서 별도로 선택합니다. 이름이 같은 프로젝트와 여러 프로필에 공유된 프로젝트가 구분되는지 확인합니다.

## 개인과 팀 워크스페이스

1. `personal`, `team` 저장용 프로필을 등록합니다. 이 이름은 검증된 계정·워크스페이스 ID가 아닙니다.
2. 공유 가능한 테스트 프로젝트를 `personal`에 등록합니다.
3. 결정 사항과 구체적인 다음 작업을 체크포인트로 저장합니다. 요청 전달뿐 아니라 도구의 저장 성공을 확인합니다.
4. `project_grant`로 `team`에도 공유합니다.
5. 진행 중인 작업을 저장·중단한 뒤 공식 로그인 절차로 계정·워크스페이스를 바꿉니다. 로컬 OAuth 완료는 실행 중인 데스크톱의 전환 완료를 의미하지 않습니다.
6. 새로 연결된 작업에서 `team`으로 `project_resume`를 호출합니다.
7. 목표·결정·다음 단계와 실제 파일 접근을 비교합니다.

서로 다른 개인 계정은 같은 OS 사용자와 같은 `CDX_SLIDER_HOME`에서 `account-a`, `account-b`로 반복합니다. 계정 전환 후 플러그인 재활성화가 필요한지도 기록합니다.

## 공유·사용량·인계

- 공유하지 않은 프로젝트는 다른 프로필의 목록에서 보이지 않고 복원이 실패해야 합니다. 다른 프로필로 몰래 재시도하지 않습니다. 앱의 공유 규칙 확인이며 OS 사용자 격리 검사는 아닙니다.
- 로그인된 기존 CLI 홈을 등록하고 `usage`를 호출합니다. 비슷한 시각의 같은 계정과 비교합니다. 실패·알 수 없는 값을 사용량 0으로 표시하지 않고, 계정 한도를 합치지 않아야 합니다.
- 내보낸 Markdown을 검토한 뒤 ChatGPT에 직접 첨부합니다. 필요한 파일은 별도로 제공합니다. 기존 대화·내장 메모리 복원을 성공 기준으로 삼지 않습니다.

## 미니바 중계와 재시작

- 미니바 프로젝트를 검증된 작업에 연결하고 현재 `threadId`로 패널을 열어 실제 표시를 확인합니다. 불러오기 요청 전달과 에이전트의 실제 답변은 별도로 확인합니다. 백그라운드·접힌 패널에서도 반복하며, 불확실한 전달은 자동 재전송하지 않아야 합니다.
- 재시작 동의는 기본 미선택입니다. 먼저 가상 호스트에서 예약·취소를 확인합니다. 실제 재시작에는 모든 작업의 저장·중단 확인이 필요합니다. 이 안내만으로 실제 계정 전환·재시작을 실행하지 않습니다.

## 결과 기록

앱 버전, 프로필 종류, 패널 표시, 도구 응답, 저장 내용 일치, 실제 파일 접근, 미검증 범위를 기록합니다. 사이드바·원래 대화 유지 여부는 별도 관찰값입니다. 비밀번호·토큰·쿠키·OAuth URL은 기록하지 않습니다.
