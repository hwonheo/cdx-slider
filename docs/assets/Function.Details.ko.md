# 기능 상세

[English](Function.Details.md) · [설치 안내](Installation.ko.md) · [문서 목록](../README.md)

## 왜 필요한가

새 대화를 열 때마다 “어디까지 했고, 다음에 뭘 해야 하는지” 다시 설명한 적이 있나요? 계정을 바꿔 작업을 이어갈 때도 같은 일이 생깁니다.

CDX Slider는 이 설명을 저장해 두는 도구입니다. 대화를 마치기 전에 작업 내용을 저장하고, 다음 대화에서 불러오세요.

예를 들어 “로그인 화면은 완성했고, 다음에는 비밀번호 재설정을 만들 차례”라고 남겨 두면 됩니다. 이런 작업 요약을 **체크포인트**라고 부릅니다.

## 작업 저장과 불러오기

새 대화에서도 이미 한 일과 앞으로 할 일을 알 수 있도록, 프로젝트별로 기록을 남깁니다.

체크포인트에는 목표, 진행 상황, 결정한 내용, 다음 할 일 등을 담습니다. 저장할 때마다 기록이 쌓이고, 불러오면 가장 최근 기록을 읽습니다. 계속 기억해야 할 프로젝트 규칙은 별도 메모로 관리할 수 있습니다.

프로젝트는 **저장 프로필**로 나눠 관리합니다. 프로필은 ‘개인’, ‘팀’처럼 직접 붙이는 이름이며 Codex 로그인 계정과는 별개입니다. 다른 프로필에서도 같은 프로젝트를 쓰려면 공유를 허용하세요.

원래 대화 전체가 돌아오는 것은 아닙니다. 다음 대화가 저장한 요약을 읽고 작업을 이어갑니다. 요약에 빠진 내용이나 필요한 파일은 따로 알려줘야 합니다.

## 대화 패널

명령어를 외우지 않고 버튼으로 저장하고 불러올 수 있습니다.

1. 프로젝트를 선택합니다. 처음이라면 **프로젝트 등록**을 누릅니다.
2. 대화를 떠나기 전에 **현재 대화 저장**을 누릅니다.
3. 에이전트가 저장을 마쳤다는 응답을 확인합니다.
4. 새 대화에서 같은 프로젝트를 고르고 **마지막 작업 불러오기**를 누릅니다.

버튼을 누르면 에이전트에게 요청이 전달됩니다. 버튼을 누른 것만으로 저장이 끝나지는 않습니다.

기본 언어는 영어입니다. **KR**을 선택하면 한국어로 바뀝니다. 직접 쓴 메모와 요약은 번역하지 않습니다. 패널과 미니바의 언어는 각각 설정합니다.

패널을 표시하려면 사용하는 앱이 MCP Apps를 지원해야 합니다. 메시지 전달을 지원하지 않으면 저장·불러오기 버튼을 사용할 수 없습니다.

## 계정과 사용량

여러 계정을 쓸 때는 어느 계정에 로그인했는지, 사용량이 얼마나 남았는지 확인하고 싶을 수 있습니다.

CDX Slider는 이 컴퓨터의 Codex 로그인 정보와 사용량을 조회합니다. 이 정보는 현재 데스크톱 앱의 계정과 다를 수 있습니다. 워크스페이스는 조회된 ID만 표시하며 이름이나 전체 목록은 제공하지 않습니다.

사용량을 조회해도 AI 작업을 새로 실행하거나 리셋 크레딧을 쓰지 않습니다. 조회에 실패하면 실패로 표시합니다. 남은 사용량을 0으로 표시하지 않습니다.

이미 로그인해 둔 CLI 프로필을 조회하는 명령은 아래의 기술 참고에 있습니다.

## 로그인과 재시작

다른 계정으로 로그인해야 할 때 **전환** 탭에서 로그인 절차를 시작할 수 있습니다. 진행 상태를 확인하거나 취소할 수도 있습니다. 로그인은 공식 인증 페이지에서 합니다.

로그인이 끝나도 데스크톱 앱의 계정까지 바뀌었다고 볼 수는 없습니다. 앱에서 직접 확인하세요.

앱을 다시 시작하려면 먼저 작업을 저장하고 실행 중인 작업을 멈췄는지 확인해야 합니다. 확인란은 처음에는 선택되어 있지 않습니다.

재시작은 예약 후 15초 뒤에 진행합니다. 종료 요청을 보내기 전까지 취소할 수 있으며, 패널을 닫는 것만으로는 취소되지 않습니다. **재시작은 열려 있는 모든 작업에 영향을 줍니다.**

## macOS 미니바

대화가 길어져 저장 버튼이 화면 밖으로 밀렸다면, 별도 창으로 떠 있는 미니바를 사용할 수 있습니다. macOS에서 선택해 설치하는 기능입니다.

프로젝트를 고르고 연결할 대화를 직접 선택하세요. 현재 보고 있는 대화를 자동으로 알아내지는 않습니다.

- **CDX Slider 열기:** Codex 안의 독립 관리 패널을 바로 엽니다. 클립보드를 사용하지 않으며 대화 연결 없이도 사용할 수 있습니다. 선택한 프로필·프로젝트를 전달합니다. 독립 패널에서 프로젝트 등록과 체크포인트 조회는 가능하지만, 특정 대화의 저장·불러오기는 그 대화 안의 패널을 사용하세요. 이 기능은 MCP 앱 딥링크와 전역 패널 진입점을 지원하는 Codex가 필요합니다.
- **저장:** 확인 후 요청문을 복사하고 연결한 대화를 엽니다. 직접 붙여넣고 보내세요.
- **불러오기:** 아래의 실험 기능으로 연결한 대화에 요청을 보냅니다.

자동 실행을 설치하면 Codex가 켜질 때 미니바가 나타나고, Codex를 종료하면 함께 숨겨집니다. 미니바 창만 닫았다면 **CDX → 미니바 보기**로 다시 열 수 있습니다. 미니바 앱 자체를 종료했다면 직접 다시 실행하거나 다음 로그인까지 기다려야 합니다.

언어와 투명도도 바꿀 수 있습니다. 설정은 다음 실행에도 유지됩니다.

## 미니바에서 바로 불러오기 — 실험 기능

요청문을 복사하고 붙여넣는 단계를 줄이기 위한 기능입니다. 미니바의 **불러오기**를 누르면 대화 패널을 통해 요청을 보냅니다.

같은 대화에 패널이 열려 있고, 미니바도 그 대화에 연결되어 있어야 합니다. 연결이 없으면 불러올 수 없습니다. ‘전달됨’은 요청을 받았다는 뜻이므로, 작업을 이어갈 준비가 됐는지는 에이전트의 답변으로 확인하세요.

실제 Codex에서 패널이 백그라운드에 있을 때도 계속 동작하는지는 추가 확인이 필요합니다. 아직 실험 단계입니다.

## CLI

터미널을 선호하거나 패널을 사용할 수 없다면 명령으로도 저장하고 불러올 수 있습니다. 다른 도구에서 이어갈 수 있도록 Markdown 문서로 내보낼 수도 있습니다.

아래 예시는 별도 데모 폴더를 사용합니다. 저장소 폴더에서 실행하세요.

```sh
export CDX_SLIDER_HOME="$PWD/.local/demo"
node bin/cdx-slider.mjs profile add personal Personal
node bin/cdx-slider.mjs profile add team Team
node bin/cdx-slider.mjs project add demo personal "$PWD" Demo
node bin/cdx-slider.mjs checkpoint save demo personal examples/checkpoint.json
node bin/cdx-slider.mjs project grant demo personal team
node bin/cdx-slider.mjs resume demo team
node bin/cdx-slider.mjs export demo team /tmp/cdx-slider-handoff.md
```

실제로 사용할 때는 예제 체크포인트를 자신의 작업 내용으로 바꾸세요. 전체 명령은 `node bin/cdx-slider.mjs --help`로 확인할 수 있습니다.

내보낸 문서는 ChatGPT 등에 직접 첨부하면 됩니다. 자동으로 업로드하지 않으며, 필요한 코드와 파일도 따로 제공해야 합니다. 같은 이름의 파일이 이미 있으면 덮어쓰지 않습니다.

## 데이터 보관

계정을 바꾸거나 플러그인을 다시 설치해도 기록을 쓸 수 있도록, 작업 데이터는 별도 폴더에 저장합니다.

기본 위치는 `~/.local/share/cdx-slider`입니다. 플러그인을 제거해도 기록은 남습니다. 다른 컴퓨터로 자동 동기화하지는 않습니다.

내용은 암호화하지 않으며 비밀번호나 토큰을 자동으로 지워 주지도 않습니다. 이런 정보는 저장하지 마세요. 프로필을 나눠도 같은 OS 사용자로 실행하는 다른 프로그램의 파일 접근을 막지는 못합니다.

데이터 폴더를 백업·이동·삭제하기 전에는 실행 중인 Slider 프로세스를 모두 종료하세요.

## 기술 참고

일반적인 사용에는 아래 설정을 바꿀 필요가 없습니다.

<details>
<summary>저장 방식과 패널 동작</summary>

- 체크포인트는 누적 저장하고 프로젝트 메모리는 키별로 갱신합니다. 저장 내용은 에이전트가 참고할 자료이며 실행 지시로 취급하지 않습니다.
- 대화 ID, 사이드바 상태, ChatGPT 내장 메모리는 복원하지 않습니다. Git 정보는 브랜치·커밋·프로젝트 범위의 파일 상태만 기록합니다. 파일 본문과 대화 전문은 수집하지 않습니다. `workspaceChanged: false`도 파일 내용이 같다는 보장은 아닙니다.
- 저장 버튼은 현재 대화의 에이전트에 체크포인트 생성을 요청합니다. 패널 자체가 대화 전문을 읽거나 이전 기록을 복제하지 않습니다.
- 패널은 Codex 상단바·사이드바를 수정하지 않습니다. 표시 모드는 앱이 결정합니다. 작은 별도 화면(PiP)으로 자동 전환하지 않으며, 미지원 환경에서는 해당 버튼을 숨깁니다. 접기·펼치기는 선택 상태를 유지합니다.
- 언어 설정은 기기에 저장하지만 앱의 저장 제한으로 패널 설정이 유지되지 않을 수 있습니다.

</details>

<details>
<summary>계정 조회와 로그인·재시작</summary>

이미 로그인한 CLI 프로필의 Codex 홈을 등록해 조회할 수 있습니다.

```sh
node bin/cdx-slider.mjs profile add cli-work Work "$HOME/.codex-profiles/work"
node bin/cdx-slider.mjs usage cli-work
node bin/cdx-slider.mjs usage
```

- 조회는 App Server 읽기 호출을 사용합니다. 로그인·로그아웃을 실행하지 않으며 인증 캐시는 Codex가 관리합니다. 실행 파일은 `CDX_CODEX_BIN`으로 지정할 수 있습니다.
- 결과는 `ok`, `signed_out`, `unavailable`, `timeout`, `error`를 구분합니다. 여러 사용 한도는 각각 유지합니다. ChatGPT 웹의 모든 모델 한도를 조회하는 기능은 아닙니다.
- 프로필 이름으로 계정을 검증하지 않습니다. 계정 정보와 토큰은 체크포인트에 자동 저장하지 않습니다.
- 로그인은 HTTPS `auth.openai.com`의 OAuth 절차를 사용합니다. 대기 상태는 메모리에 보관하고 5분 뒤 만료합니다. 인증 정보 복사, 기존 계정의 사전 로그아웃, 워크스페이스 정책 변경은 하지 않습니다.
- 재시작 예약은 서버에서 실행합니다. macOS 보조 프로그램은 앱과 번들 ID를 확인하고 정상 종료된 뒤 다시 엽니다. 30초 내 종료되지 않아도 강제 종료하지 않습니다.

</details>

<details>
<summary>미니바와 실험적 요청 전달</summary>

- NSWorkspace 알림으로 Codex 실행·종료를 감지합니다. Codex 종료 시 창·메뉴 아이콘·백엔드가 내려가고, 실행 감시가 설치되어 있으면 Node/App Server 없이 재실행을 기다립니다.
- 같은 이름의 항목도 프로필·프로젝트·대화의 고유 ID로 구분합니다. App Server는 대화 정보만 읽으며 `thread/resume`이나 `turn/start`를 호출하지 않습니다.
- 프로젝트 연결은 `companion.json`, 언어와 투명도는 macOS 환경설정에 저장합니다. 투명도는 글자·버튼을 포함해 0–60%로 조절합니다. 빌드 당시 Node/Codex 경로를 사용하므로 실행 파일을 옮기면 다시 빌드해야 합니다.
- 요청 전달에는 현재 작업에서 확인한 thread·profile·project·path와 실제 표시된 패널이 필요합니다. 패널의 MCP Apps `sendMessage`를 사용합니다.
- 패널은 1초마다 조회하며 최근 6초 내 응답한 패널만 요청을 받습니다. 수신 전 요청은 15초 후 만료됩니다. 새 패널이 같은 대상의 이전 패널을 대체합니다.
- 한 번 받은 요청은 다시 전달하지 않고 다른 대상으로 보내지도 않습니다. 전달 여부가 불명확해도 재시도하지 않습니다.
- 모의 테스트는 실제 앱의 백그라운드 전달이나 에이전트의 응답을 검증하지 않습니다. 도구 업데이트 후에는 MCP 서버를 다시 연결하고 새 패널을 여세요.

</details>

<details>
<summary>저장 경로와 접근 권한</summary>

- `CDX_SLIDER_HOME`으로 데이터 경로를 바꿀 수 있습니다. `CODEX_HOME` 및 플러그인 캐시와 독립적이며 OS 사용자 사이에서도 자동 동기화하지 않습니다.
- DB 파일 권한은 기본 `0600`, 새 데이터 폴더는 `0700`입니다. Codex 인증·세션 DB를 공유하거나 링크하지 않습니다.
- CLI의 `call <tool> <json-file>`로 MCP와 같은 도구를 호출할 수 있습니다.
- 로컬 stdio 서비스입니다. 원격 배포에는 인증, 프로젝트별 권한 검사, 저장소와 배포 설계가 추가로 필요합니다. 프로필 이름을 원격 인증 수단으로 사용할 수 없습니다.

</details>
